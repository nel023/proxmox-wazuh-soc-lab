# **Syslog Forwarding – SOC Lab**

## **Overview**

This document is reserved for the future implementation of **centralized syslog forwarding** within the SOC home lab.

Syslog forwarding is currently **out of scope** to allow focused learning on:

Endpoint-level telemetry

* Wazuh agent monitoring
* Detection of attacks directly from hosts
* Understanding alert generation and correlation in Wazuh

Centralized syslog collection will be introduced in a later phase once endpoint monitoring fundamentals are fully established.



## **Notes**

Syslog forwarding is more relevant in larger, multi-device environments

Future implementation may include:

* Network device log ingestion
* Linux service log aggregation
* Correlation with Wazuh alerts
